# Paquets ANKI_TWO

Contenu du catalogue de l'appli ANKI_TWO, téléchargé à la demande par l'appli.
Généré automatiquement par `content/paquets/build.mjs` (dépôt de l'appli) : ne pas modifier à la main.

- `manifest.json` : liste des paquets (version, nombre de cartes, taille, empreinte SHA-256).
- `decks/<slug>.json` : un fichier par paquet.
